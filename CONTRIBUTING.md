# Contributing

Thanks for wanting to improve Aven.

The most helpful way to propose new functionality is to open an issue. You do
not need to prepare a formal proposal. Share whatever context you have, though
concrete use cases, examples, and current workarounds are especially useful.

Small, narrowly scoped pull requests are welcome. Substantial changes are
generally implemented by the maintainer rather than accepted as external pull
requests. Reviewing and integrating a large external change often takes more
time than implementing it directly.

If you would like to see a substantial change, please open an issue. Discussion
helps shape the project and prioritize work, but does not guarantee that a
proposal or pull request will be accepted.

For focused package checks and the full validation gate, see
[TESTING.md](TESTING.md).
